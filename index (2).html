📱 Installer l'application

Une fois installée, l'application fonctionne sans internet, comme une vraie appli sur votre téléphone.

1

Ouvrir dans Safari

Ouvrez ce fichier dans Safari (pas Chrome). Tapez le chemin du fichier ou envoyez-le par mail et ouvrez-le.

⚠️ Ça doit être Safari obligatoirement pour installer sur iPhone
2

Appuyer sur Partager

En bas de l'écran, appuyez sur l'icône Partager (carré avec une flèche vers le haut ↑)

3

Sur l'écran d'accueil

Faites défiler vers le bas et appuyez sur "Sur l'écran d'accueil"

4

Confirmer

Appuyez sur "Ajouter" en haut à droite. L'icône apparaît sur votre écran d'accueil !

1

Ouvrir dans Chrome

Ouvrez ce fichier dans Google Chrome.

2

Menu Chrome

Appuyez sur les 3 points ⋮ en haut à droite

3

Ajouter à l'écran d'accueil

Appuyez sur "Ajouter à l'écran d'accueil" puis "Ajouter"

1

Double-cliquez sur index.html

Le fichier s'ouvre dans votre navigateur (Chrome recommandé).

2

Créer un raccourci

Glissez l'onglet sur votre bureau, ou clic droit → "Enregistrer sous favori".

3

Imprimer les factures

Le bouton "Imprimer / PDF" ouvre la fenêtre d'impression. Choisissez "Enregistrer en PDF" pour garder une copie numérique.

💾 Sauvegarde des données

Toutes les factures sont sauvegardées automatiquement dans le téléphone / ordinateur. Pour sauvegarder manuellement :

💡 Exportez régulièrement vos données et gardez le fichier dans votre Google Drive ou iCloud
